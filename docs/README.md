# Docs drafts

`v2/typescript/server/authentication/providers/scalekit.mdx` is a cookbook-style how-to: protect an mcp-use server with Scalekit OAuth 2.1.

The page follows Scalekit docs writing style (sentence-case outcome headings, conclusion first, `<Steps>`, troubleshooting in `<details>`). It is not published on mcp-use or Scalekit docs yet.

Until `mcp-use/oauth/scalekit` ships, import the adapter from [`../oauth/scalekit.ts`](../oauth/scalekit.ts). The [repo README](../README.md) is the clone-and-run runbook for this example.
